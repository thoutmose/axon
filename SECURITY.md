# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through this repository’s **Security → Report a vulnerability** form. Do not open a public issue, and do not include real personal or health data in the report.

You should get an acknowledgement within 7 days. Please allow up to 90 days for a fix before public disclosure; we will agree a date with you.

## Supported versions

Axon has no release yet. Until 1.0, only the latest commit on `main` receives security fixes.

## Scope

In scope: this repository’s code, its default configuration, and its deployment files. Out of scope: third-party services Axon connects to (report those to their owners), and attacks that require physical access to the host.
